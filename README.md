# Kick (DVR / Stream Rewind) Plugin for Grayjay

> **Модифікований плагін Kick для Grayjay з підтримкою повної перемотки (DVR) живих стрімів.**

За замовчуванням офіційний плагін Kick у Grayjay використовує Low-Latency HLS потік із буфером лише ~30 секунд. Цей плагін підключає повнорозмірний DVR-маніфест (`stream.kick.com`), що дає змогу **перемотувати прямий ефір на будь-яку точку з самого початку стріму** (як на офіційному сайті Kick).

---

## ⚡ Швидке встановлення в Grayjay

### Варіант 1: В один клік (якщо встановлено Grayjay)
Натисніть на посилання:
👉 **[Встановити Kick (DVR) в Grayjay](grayjay://plugin/https://raw.githubusercontent.com/MarianQQQ/grayjay-wtv/kick/KickConfig.json)**

---

### Варіант 2: За посиланням вручну
1. Скопіюйте це посилання:
   ```text
   https://raw.githubusercontent.com/MarianQQQ/grayjay-wtv/kick/KickConfig.json
   ```
2. Відкрийте **Grayjay**.
3. Перейдіть у **Sources** (Джерела) -> натисніть **+** (Додати джерело).
4. Виберіть **Install from URL** (Встановити за URL).
5. Вставте скопійоване посилання та натисніть **Install**.

---

## ⚙️ Налаштування
У налаштуваннях плагіна в Grayjay доступний параметр:
* **Live Stream DVR (Rewind)** (Увімкнено за замовчуванням):
  * **ON:** Повна шкала часу від початку стріму (затримка прямого ефіру ~15-20с).
  * **OFF:** Стандартний потік із мінімальною затримкою ~2с (буфер 30 секунд).

---

## 🛠 Зміни порівняно з оригінальним плагіном FUTO:
1. Автоматичний пошук активного VOD-запису трансляції через `https://kick.com/api/v2/channels/{slug}/videos`.
2. Підключення маніфесту `stream.kick.com` (`#EXT-X-PLAYLIST-TYPE:EVENT`) для повного таймлайну.
3. Безпечний fallback: якщо стрімер вимкнув VOD або запит не вдалося виконати, плагін непомітно повертається до звичайного прямого ефіру.
4. Окремий Plugin ID — не конфліктує зі стандартним плагіном Kick від FUTO.
